# MedCare Hospital Management System

A full-featured Hospital Management System with separate dashboards for **Patients**, **Doctors**, and **Admin**.  
Built for managing appointments, medical records, doctors, patients, medicines, and notifications in a structured and user-friendly way.

---

## 🔗 Live Demo  

---

## 🏥 Project Overview

MedCare is a web-based hospital management platform that provides:

- Patient self-service portal  
- Doctor workspace for appointments & records  
- Admin control panel for managing doctors, patients, appointments, and medicines  

Each role has its own UI and permissions.

---

# 🚀 Features by User Role

---

# 👨‍⚕️ Patient Panel

### **Dashboard Overview**
- Welcome message with health activity summary  
- Upcoming Appointments count  
- Past Appointments count  
- Total Doctors available  
- New Notifications  

### **Patient Menu**
- Home  
- My Appointments  
- View & Manage Appointments  
- Medical Records  
- Notifications  
- Profile Settings  
- Logout  

### **Patient Functions**
- View upcoming & past appointments  
- Search doctors by name/specialty  
- Book new appointment  
- View prescriptions & medical records  
- Receive notifications (lab results, reminders)  

---

# 🧑‍⚕️ Doctor Panel

### **Dashboard Overview**
- Appointments Today  
- Total Patients  
- Total Appointments  

### **Doctor Menu**
- Home  
- My Appointments  
- My Patients  
- Patient Records  
- Medicines  
- Profile Settings  
- Logout  

### **Doctor Functions**
- View today, upcoming, and past appointments  
- Search patients  
- Manage patient records  
- View patient medical history  
- Write prescriptions  
- Manage medicines  
- Access patient list  

---

# 🛠 Admin Panel

### **Admin Dashboard**
- Total Patients  
- Total Doctors  
- Total Medicines  
- Today’s Appointments  

### **Admin Menu**
- Dashboard Home  
- Patient List  
- Doctor Management  
- Appointment Management  
- Medicine Management  
- Profile Settings  
- Logout  

### **Admin Capabilities**
- Add / View / Edit / Delete doctors  
- Manage patient list  
- Manage medicines  
- View all appointments  
- Confirm / Complete / Delete appointments  
- Filter appointments by doctor, patient, date, status  

---

# 📚 System Modules Explained

### **1. Appointment Management**
- Book, confirm, cancel, and complete appointments  
- Date-based & ID-based filtering  
- Status management (Confirmed, Completed, Pending)  

### **2. Patient Management**
- View patient records  
- Access medical history  
- Track visit dates  
- Manage patient data  

### **3. Doctor Management**
- Add/edit doctors  
- Manage profiles & availability  

### **4. Medicine Management**
- Add new medicines  
- View/edit existing medicines  

### **5. Notification Module**
- Appointment reminders  
- New lab result notifications  

### **6. Medical Records Module**
- Prescriptions  
- Previous visits  
- Health reports
